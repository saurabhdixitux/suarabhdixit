Process

My Design Process

Design isn't a straight line. I utilize a fluid, interconnected approach to balance deep discovery with rapid execution.

01 / DISCOVERY

Uncovering the "Why"

Through contextual inquiry, stakeholder interviews, and data review, I strip away assumptions to map out the actual user environment and core business objectives.

02 / SYNTHESIS

Pattern Making

Turning raw data into actionable insights using affinity mapping, JTBD, and journey mapping.

03 / ARCHITECTURE

Structuring Chaos

Before drawing pixels, I define the skeleton. Heavy focus on Hub-and-spoke IA, progressive disclosure, and user flows to handle enterprise-level complexity seamlessly.

04 / DESIGN

Crafting the UI

Translating structures into high-fidelity Figma components, prototyping micro-interactions, and building scalable systems.

05 / VALIDATE & SHIP

Testing & Handoff

Rigorously testing prototypes via usability sessions and SUS scoring. Final delivery includes meticulous developer handoff specs, token mapping, and QA support.
